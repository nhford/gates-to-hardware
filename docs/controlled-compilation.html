Do reversals survive routing and translation alone?

This experiment follows the IBM New / Qiskit Level 1 total-gate reversals on CX-native backends, plus qe_qft_4 as the QFT comparator. Logical optimization remains Qiskit Level 3. Both hardware paths use fixed placement, SABRE routing, and explicit native translation with gate-direction correction.

The compilation target contains gate availability and connectivity. Gate errors, durations, and coherence properties are removed. SABRE uses the lookahead heuristic, 20 trials per seed, and matched seeds 0–4. There is no cancellation or resynthesis stage. Equivalence and native instruction support are checked for every output.

Compilation policy

The explicit pass sequence is SetLayout → FullAncillaAllocation → EnlargeWithAncilla → ApplyLayout → SabreSwap → CountRoutingSwaps → BasisTranslator → GateDirection → BasisTranslator. Basis translation decomposes unsupported instructions, including routing SWAPs. It does not run a general optimization loop.

This experiment isolates required routing and translation overhead. Remaining gate sequences may contain redundancies that preset Level 1 would simplify. SABRE minimizes a connectivity heuristic; total native gate count is an evaluation metric.
