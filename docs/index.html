Do logical savings survive hardware compilation?

How well do logical circuit metrics predict compiled cost and fidelity, and when do they mislead? This experiment compares VOQC, hardware-unaware Qiskit, and Quartz on 37 circuits from GuoQ’s Nam RZ benchmark suite.

Experimental setup

  1. Baseline. Compile the original Nam circuit directly for the target.
  2. Candidate. Optimize the same original circuit with VOQC, Qiskit level 3 without a backend, or Quartz’s bounded rewrite search in the Nam RZ basis. Check the optimized circuit against the original, then compile with the same settings as the baseline.
  3. Hardware compilation. Use Qiskit compilation levels 0–3, SABRE, and matched seeds 0–4. Level 0 translates to native gates and routes the circuit. Level 1 adds lightweight optimizations such as inverse gate cancellation. Levels 2 and 3 apply more aggressive optimization. Each target uses a fixed connected patch matching the circuit’s width. Compare the paired results before taking the median across seeds.

IBM backend choice

Marrakesh is a 156-programmable-qubit IBM Heron r2 system with native CZ gates. Sherbrooke is an older 127-qubit Eagle system and appears here as a historical reference. The Marrakesh comparisons use Qiskit’s bundled FakeMarrakesh snapshot, with calibration dated February 26, 2025. All runs are local compilations against saved targets, with no jobs submitted to IBM hardware. Each circuit still uses a connected patch matching its width. IBM Quantum compute resources

How to read the chart

  • Logical savings. Original minus optimized gate count, two-qubit gate count, or depth in the common h/x/rz/cx basis.
  • Compiled savings. Baseline minus candidate native gate count, native two-qubit gate count, depth, estimated execution duration, or inserted SWAP count. SWAPs are counted before basis translation.
  • Fidelity gain. Candidate minus baseline in percentage points, using the product of calibrated gate fidelities on the mapped physical qubits. It is a proxy based on historical gate calibrations.

The chart reports Spearman rank correlation for the visible selection. A reversal is a point whose logical and compiled changes have opposite signs. Multiple observations share an input circuit, so the correlation is descriptive.

Aer fidelity check

The Aer fidelity check uses five-qubit circuits compiled for Manila and Lima. Qiskit Aer simulated the compiled operations using backend-derived noise models. Average fidelity was evaluated against the ideal compiled unitary. Aer and the calibration proxy agreed on 14 of 16 optimizer rankings. On hlf_5, the proxy tied the optimizers on both targets while Aer favored VOQC.

Equivalence checks

Circuits through eight qubits use full-unitary checks. Wider circuits use three seeded product-state probes, accounting for output layout and requiring a shared global phase. The wider checks validate sampled behavior.
